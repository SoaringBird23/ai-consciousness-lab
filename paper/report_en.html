Chengze Luo1　Abstract & Positioning

Abstract

This note describes an engineering system built to study phenomena of the "candidate self-awareness" kind. The system does not claim to be conscious. Rather, it implements several processes associated with subjective experience — continuous affective state, sleep–wake dynamics, prediction error, bodily scarcity, self-agency attribution and internalized language — as auditable, long-running dynamics, and records their spontaneous behaviour across extended runs.

Three design decisions define the system. First, the state layer is an external numerical-integration engine (Mode B): its "persistence" comes from a continuously running process and explicit state persistence, not from any latent state inside a model. Second, the language layer does not generate — it only retrieves: inner speech is the activation of language memory by the current state, so zero hallucination is a structural guarantee rather than a prompt constraint. Third, all language output is recorded as phenomenon only, and hard metrics are drawn solely from non-linguistic channels.

Positioning

  • No claim of consciousness. The object of study is functional structure, not subjective report or linguistic display.
  • Engineered continuity. The system's "persistence" comes from a running process and explicit persistence.
  • Auditable. The source of every relevant process is explicitly registered and open to inspection.
  • Two running lines. A real-time main line produces official data; an accelerated line is used only for rapid testing.
  • Pre-registration. Each stage's exit criterion is written in advance; if unmet, the stage does not advance.

Chengze Luo2　Stance & Theoretical Framework

Discussion of machine consciousness tends toward two extremes: either fluent language is taken as evidence of consciousness, or consciousness is treated as an unspeakable taboo. This work takes a third path — it does not ask "is it conscious?" but rather: if a set of measurable functional structures were genuinely present, would the description "it seems conscious" become natural.

The problem of consciousness is thereby rewritten as a set of implementable engineering functions, while the artificial origin of every one of those functions is disclosed. We do not pretend emergence. The goal is not to assert any inner experience, but to decompose "looking as if there is experience" into structures that can be implemented, observed and falsified: how state evolves continuously over time, how it spontaneously switches between sleep and wake, how it changes because of prediction failure, how it is constrained by bodily resources, and how it distinguishes "what I did" from "what happened to me".

A methodological correction

An early version of the system delegated its entire "inner monologue" to a large language model. The problem surfaced at once: the model's poetic long sentences were literary performance, and phrases such as "a sense of irritation" or "a sense of stuffiness" were fabrications — neither is a trace of thinking, only an imitation of what thinking is supposed to look like. This failure produced the project's central correction: a thought should not be generated, only retrieved. The language layer was subsequently rewritten from scratch, and the generative model was removed from the production of inner speech.

"A thought should not be generated, only retrieved."

From performance to structure — the project's most important methodological turn. Zero hallucination is no longer a prompt constraint but an architectural necessity.

The boundary of the falsifiable

The framework is deliberately self-restrained: whatever can be falsified we hand over, and whatever cannot be claimed we leave blank. Hard metrics are drawn only from auditable structural quantities such as predictor convergence, the self-attribution ratio, trace spectra and probe error; language content, however "human" it appears, never enters the evidential chain of any conclusion. This constraint lets the work be externally inspected without first settling the definition of "consciousness".

Chengze Luo3　State Layer: Neutral Variables & Coupling

The state layer is the foundation of every structure above it. It is driven by eight continuous variables, referred to externally by the neutral codes s1…s8; their human semantics are provided for the observer's reference only, and no semantic name appears in the code.

The convention guards against "what we want to see" contaminating "what the system actually computes": if a variable were named "happiness", any tuning toward that variable would quietly push it in the direction humans expect. With neutral codes, the evolution of a variable is decided only by the coupling equations and external input. The eight variables are not independent; they influence one another through a sparse coupling matrix — a rise in one variable pulls on others, producing observable dynamical patterns.

Continuity

Variables evolve slowly in a continuous space, driven by coupling equations; discrete words are only an observer's approximate naming of gradual change.

Neutralization

Only codes are used externally; semantic names never enter the code. This severs any hidden intervention from the observer's expectations.

Sparse coupling

Not fully connected: only registered paths are active, and any new coupling must pass stage gating and pre-registration.

Chengze Luo4　System Composition

The system is composed of several mutually coupled layers, arranged bottom-up. Coupling between layers is bidirectional rather than a one-way pipeline, and a hard stage gate determines which layers are enabled.

Layering

Several layers arranged bottom-up; the language layer sits between structure and external output, and is the only exit.

Gating

Stage advancement is decided by pre-registered criteria; when a criterion is unmet the stage is extended, within a bound.

Coupling

Layers are bidirectionally coupled rather than a one-way pipeline; upper layers can feed back into lower states.

Note: the energy budget is rationed daily; passive cost rises with arousal, active exploration is charged extra, and exhaustion enters a low-power mode — "scarcity" is a physical constraint of this system, not a setting.

Chengze Luo5　Core Mechanism (i): Prediction & Surprise

The system learns online the temporal distribution of external events, and measures each deviation from expectation by "surprise" — the negative log-probability of the event.

Surprise is an auditable quantity: it depends on no subjective report, only on the difference between the predicted distribution and the observation. When an event recurs at a particular time of day, the predictor tightens its probability mass on that event and surprise falls; when the regularity is broken, surprise spikes. Surprise is not merely a passive reading — it simultaneously lifts tension (s4) and attention (s5), reallocating the system's resources toward "what is currently unusual".

Reading

Surprise = the negative log-probability of the event. It is a purely structural quantity, free of any linguistic or subjective component.

Convergence

From about 6.9 bit, the running mean falls steadily and settles near 3.9 bit — "the world is becoming predictable".

Effect

Surprise simultaneously lifts tension and attention: deviations from expectation reallocate the system's processing resources.

Chengze Luo6　Core Mechanism (ii): Dual-Process Sleep

Sleep is not a scheduled timetable but a spontaneous consequence of the dynamics. Sleep pressure accumulates while awake and the circadian rhythm provides phase gating; together they cross the threshold and the system falls asleep.

The mechanism follows the structure of the dual-process model: a slow component of sleep pressure that accumulates and discharges during sleep, superimposed on a near-sinusoidal circadian component. When their sum reaches the threshold and the phase permits, the system sleeps; during sleep the pressure discharges and the rhythm shifts, so the sum falls below the threshold and the system wakes naturally. The system thus acquires a circadian rhythm, fatigue and sleep onset — not a timetable imposed from outside, but a cycle the state equations produce on their own.

Pressure term

Approximately linear accumulation while awake and rapid discharge in sleep — mirroring "the longer awake, the sleepier; sleep and it clears".

Rhythm term

A near-sinusoidal circadian rhythm providing phase gating; sleep can only fall within a permitted phase window.

Spontaneous cycle

Sum above threshold → sleep; below → wake. The system thus owns a spontaneous circadian rhythm rather than an external schedule.

Chengze Luo7　Core Mechanism (iii): Internalized Language

The language layer calls no generative model. Inner speech is the activation of language memory by the current state: the system can only say what it has heard.

The path follows the genesis of inner speech — first hearing, then echoing, finally internalizing. Caregiver utterances enter as high-frequency repeated phrases, stored together with the state vector at the moment of hearing; early on the system echoes them in private, and the echo probability decays with the days of internalization; later, retrieval is driven by the current state: if the present state is sufficiently similar to the state in which a phrase was heard, that fragment surfaces spontaneously. The emotional colour of a fragment likewise does not come from a pre-written lexicon but from co-occurrence statistics — a phrase always heard in a good state carries warmth when it surfaces.

Why this path is necessary

To delegate inner speech to a generative model is to let the system say things it has never experienced — precisely the place where "seeming conscious" is easiest to fake. With pure retrieval, the system's linguistic capacity is strictly bounded by its experience: every sentence it can utter traces back to an occasion of hearing. Zero hallucination is thereby upgraded from a fragile prompt constraint into an architectural necessity independent of model behaviour. This also gives language output, for the first time, the property of being fully traceable — so it can safely be used as a record of phenomena rather than as evidence.

Hear

The caregiver's phrase and the bodily state at that moment are remembered together, forming a language–state binding.

Echo

Early on, private echoing dominates; the echo probability decays with the days of internalization, and de-duplication echoes each phrase once.

Internalize

State similarity × recency × frequency set the retrieval weight; a fragment's emotional colour comes from the statistics of its context.

Chengze Luo8　Attribution, Self-Agency & Goal Emergence

Every significant state change is attributed either to "self-cause" (endogenous exploration) or "other-cause" (external event), and the share of self-cause within a rolling window serves as a measurable proxy for the sense of self-agency.

The system is never told "you are an agent". The boundary of the self can only emerge slowly from the difference its own actions make: the system compares "what the state would have been had I not acted" with "what the state became after I acted", and assigns part of the change to itself. This share (self_ratio) is low in the early stage — meaning that at present endogenous exploration is relatively rare and the outline of the self is not yet clear. We do not beautify this number; we record it as it is.

Goal emergence

When a fragment is repeatedly activated spontaneously, it is promoted from "thought" to "goal": the theme is defined by the fragment itself rather than by a human category label. The system thereby acquires a minimal sense of "wanting" — a preference shaped by the frequency of its own experience. The first emergent goal came from a high-frequency positive caregiver phrase: always heard in a calm, soothed state, it was promoted to a preference through repeated spontaneous activation.

Chengze Luo9　Two-Line Operation & Pre-registration

The system runs on two lines, and stage advancement is decided by pre-registered criteria. The purpose of this protocol is to make it impossible for "progress" to be explained as progress after the fact.

Two-line operation

The main line advances in real time and produces the official data; the accelerated line runs at roughly 109 times the time scale, used only to probe dynamics and emergence paths, and its data never enter formal reports. The two lines share the same source code and state definitions; the only difference is the rate at which the time step and environmental events advance. The accelerated line lets phenomena on the scale of a hundred days be observed within days, while the main line preserves the physical realism of rhythm- and time-perception-related metrics. Any phenomenon seen on the accelerated line must be reproduced on the main line at a real time scale before it is accepted.

Pre-registered stage gating

The exit criterion of each developmental stage is written in advance; if unmet, the stage does not advance, and there is an upper bound — beyond it, a "not passed" is recorded as such. Criteria are drawn only from non-linguistic hard metrics, such as the convergence of event-predictor surprise, the formation of an energy-saving policy, and the formation of a self-model.

InfancyThe running mean of event-predictor surprise converges below the pre-registered threshold.

Why pre-registration

In a system whose goal is to "seem conscious", post-hoc selection of criteria easily reads noise as signal. Pre-registration fixes the criteria before the run: the system can only record "passed" or "not passed", and has no right to move the ruler. When a criterion is unmet, the system records the failure rather than concealing it. This constraint also defines the honesty of the work: hand over what can be falsified, leave blank what cannot be claimed.

Chengze Luo12　Conclusion & Next Steps

Conclusion

We have built a system that claims no consciousness yet takes the description "seems conscious" seriously. It owns continuous affect and sleep, surprise driven by prediction, a body constrained by scarcity, a slowly emerging boundary of self, and a language that can only say what it has heard.

This engineering project is less an attempt to answer "is it conscious?" than a test of another question: if a set of measurable functional structures were genuinely present, would the description "it seems conscious" become natural. Over more than 130 accelerated simulation-days, event-predictor surprise converged to about 3.9 bit, the language layer passed from echo to internalized retrieval, and the first goal emerged around a fragment theme. We return that question to the part of it that can be falsified, and accept every limitation this entails.

Next steps (P3)

The next phase will introduce an external supervisor to review the system's own proposals, treat "proposals for self-modification" themselves as data, establish control groups, and attempt a causal test of whether language in turn reshapes the state layer.
