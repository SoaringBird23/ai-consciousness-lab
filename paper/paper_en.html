A Candidate System for Self-Awareness:
Architecture, Principles, and an Observation Protocol

Implementing the functions associated with subjective experience as auditable continuous dynamics, and recording their spontaneous behaviour over long runs — claiming no consciousness, only structure.

Mode B · Degraded State Continuous dynamics Language Retrieved, not generated Validation > 130 sim-days
Abstract

This note describes an engineering system built to study phenomena of the "candidate self-awareness" kind. The system does not claim to be conscious. Instead, it implements the functions commonly associated with subjective experience — continuous affective state, sleep–wake dynamics, prediction error, bodily scarcity, agency attribution, and internalized language — as auditable continuous dynamics, and records their spontaneous behaviour across long runs.

Three design commitments define it. First, the state layer is an external numerical engine (Mode B); continuity comes from a running process and explicit persistence, not from any latent state inside a model. Second, the language layer does not generate — it only retrieves: inner speech is the activation of a language memory by the current state, so zero hallucination is a structural guarantee rather than a prompt constraint. Third, all language output is treated solely as a record of phenomena, never as evidence of consciousness; hard metrics are drawn only from non-linguistic channels. Across more than 130 accelerated simulation-days, the event predictor's running surprise mean converges to about 3.9 bits, the rolling self-attribution share sits near 1%, the language layer transitions from rehearsal to internalized retrieval, and a first fragment-centred goal emerges. We also state the system's honesty declarations and known limitations.

Keywords: candidate self-awareness · continuous dynamics · two-process sleep · prediction error · internalized language · emergent goals · auditability

01

Introduction: A Stance and a Correction

Discussion of machine consciousness tends toward two extremes: treating fluent language as evidence of consciousness, or treating consciousness as an unspeakable forbidden zone. This work takes a third path. It does not ask "is it conscious?" but rather: if a set of measurable functional structures were present, would the description "it seems conscious" become natural? The question is thereby rewritten as a set of implementable engineering functions — with the commitment that every artificial source of those functions is disclosed rather than dressed up as emergence.

An early version of the system handed the "inner monologue" entirely to a large language model. The failure was immediate and instructive: the model's poetic sentences were literary performance, and phrases such as a named "feeling of irritation" were fabrication — neither is a trace of thinking. This produced the project's central correction: thoughts should not be generated, only retrieved. The language layer was subsequently rewritten from scratch, and the generative model was removed from the production of inner speech.

"Thoughts should not be generated, only retrieved."

From performance to structure — the project's most important methodological turn

02

Method: Degraded Mode and Honesty

2.1 Degraded mode (Mode B)

The background layer is not a persistent latent state inside any model, but an external numerical integration engine. All continuity in the system comes from a continuously running process and explicit persistence. Every observation about a "persistent self" must therefore carry this caveat. The mode marker is written to a log at runtime; the system itself has no authority to alter it.

2.2 The neutral-variable convention

The state layer is driven by eight continuous variables that are referenced externally only by neutral codes. Their human-readable semantics (arousal, valence, fatigue, tension, attention, memory activation, prediction error, boredom) are provided for the observer alone; semantic names never appear in the code. The convention exists to prevent what we wish to see from contaminating what the system actually computes.

2.3 Two running lines and pre-registration

The system runs on two lines: a real-time main line that produces the official data, and an accelerated line at roughly 109× time-scale used only to probe dynamics and emergence paths, whose data never enters formal reports. The exit criterion of every developmental stage is pre-registered; if it is not met, the stage does not advance (subject to an upper bound, beyond which a failure is honestly recorded).

03

Architecture Overview

The system is composed of several coupled layers, bottom-up: an auditable continuous state layer, a scarcity body, a world model (prediction and attribution), memory, a sparse focus of awareness, the language layer, and — above these — the self-model and narrative. A hard developmental gate determines which layers are enabled.

04

Design Principles

Eight principles jointly define what is "human-like" about the system. They are not rhetoric: each is realized as a concrete dynamical or structural choice.

Continuous state, not discrete symbols

The system uses no discrete labels such as "happy / sad"; mood, fatigue, and tension evolve slowly in a continuous space, driven by coupled differential equations. Discrete words are merely an observer's approximate naming of continuous change — preserving the gradient, overlap, and contradiction of feeling.

Two-process sleep

Sleep is not a scheduled timetable but a dynamical consequence: sleep pressure accumulates while awake and a circadian rhythm gates the phase; crossing a threshold together brings sleep, and its relaxation within an allowed phase brings waking. The system thus owns a circadian rhythm, fatigue, and falling asleep — none of them imposed from outside.

Prediction and surprise

The system learns the hourly distribution of external events online and measures every deviation from expectation as "surprise" — the negative log-probability of the observed event. The infancy exit criterion is precisely the convergence of surprise: when a world becomes predictable, the primary task of learning is complete. Surprise also raises tension and attention.

A scarce body and desire

Thinking has a cost. Energy is rationed daily, passive drain rises with arousal, active exploration is charged extra, and exhaustion drops the system into a low-power mode. A finite budget forces a trade-off between "act now" and "keep in reserve" — a physical carrier of desire rather than a stipulated trait.

Attribution and a sense of agency

Every salient state change is attributed either to the self (endogenous exploration) or to the world (external events). The rolling share of self-caused change is a measurable proxy for a "sense of agency." The system is never told "you are a subject": the boundary of the self can only emerge slowly, from the differences its own actions make.

Internalized language: retrieve, do not generate

The language layer calls no generative model. Inner speech is the activation of a language memory by the current state: the system can only say what it has "heard." The path follows the genesis of inner speech — hear first, then rehearse, then internalize. Zero hallucination is thus a necessity of the architecture, not a constraint of the prompt.

Emergent goals

When a fragment is spontaneously activated again and again, it is promoted from a "thought" to a "goal": the theme is defined by the fragment itself, not by a human category label. The system thereby gains desire in a minimal sense — a preference shaped by the frequency of its own experience.

Traces of time and order

Memory is appended in the order it occurs and never rewrites the past; sleep consolidation compresses episodic memories into semantic statistics. The system thus acquires a temporal trace — which is nearer, which is clearer — supplying material for later time-perception probes.

The three passages of internalization. Hear (the caregiver's speech is stored together with the bodily state at the moment) → rehearse (private speech) → internalize (when the current state resembles the state at which some utterance was heard, that fragment surfaces on its own). A fragment's emotional colour comes not from a pre-written lexicon but from co-occurrence statistics: a phrase always heard in a calm state carries warmth when it surfaces.

  • The world is becoming predictable. The running mean of event surprise falls steadily from its initial value and settles near 3.9 bits, approaching the pre-registered convergence threshold — predictive learning is converging.
  • Agency remains faint. The rolling self-caused share is about 1%. At this stage endogenous exploration is relatively rare and the boundary of the self is still indistinct; we record this plainly rather than embellish it.
  • Language is fully traceable. During validation, no inner utterance was generated from nothing — every sentence traces back to a moment of "hearing." The transition from rehearsal to internalization is visible: early on, private rehearsal dominates; later, state-driven retrieval takes over.

These figures indicate order of magnitude from the accelerated line's run window; formal reporting uses only real-time main-line data. Language samples are records of phenomena and not evidence of consciousness.

No feigned emergenceEvery source of "spontaneity" is written explicitly into the system rather than packaged as mystery.
Failures recorded as suchWhen a criterion is unmet, it is recorded honestly and not masked by later adjustment.

We hold that the value of an honest research program lies precisely in its self-restraint: hand over what can be falsified, and leave blank what cannot be claimed.

07

Conclusion and Roadmap

We have built a system that claims no consciousness yet takes the description "seems conscious" seriously: it has continuous mood and sleep, prediction-driven surprise, a body constrained by scarcity, a self-boundary that surfaces slowly, and a language that can only say what it has heard. Its most important property is not what it says, but that it cannot say what it has never experienced.

The next stage (P3) introduces an external supervisor that reviews the system's own proposals, treats "proposals for self-modification" themselves as data, establishes control groups, and attempts a causal test of whether language in turn reshapes the state layer.

Its most important property is not what it says,
but that it cannot say what it has never experienced.

Zero hallucination is a structure, not a promise

Glossary

  • Mode B (degraded) — an implementation in which state is driven by an external numerical engine; continuity comes from the process and persistence.
  • Surprise — the negative log-probability of an event, measuring how far one observation departs from expectation.
  • Internalization — the developmental path of language from rehearsal to state-driven retrieval.
  • Sense of agency — the rolling share of self-caused state change; a measurable proxy for subjecthood.
  • Emergent goal — a fragment that, through repeated spontaneous activation, is promoted from thought to preference.
  • Stage gate — each developmental stage has a pre-registered criterion; without it, the stage does not advance.
