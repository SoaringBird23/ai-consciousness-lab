一句话命题

系统的路线与语言模型相反：它不生成文本，只能检索它听过的话；它是一个持续发育的动力学个体（非 LLM、零生成、零提示词），用来把"机器意识"这个问题变成可测的，而不是去宣称一个答案。

三个自认为最硬的点

  1. 连续、不可回退的个体史。单进程常驻 + 全量落盘，kill -TERM 后重启状态与仿真时钟续接。这恰好是 Dehaene / Naccache 指认 Claude 缺的两样之一（身体、自传体记忆）。
  2. 自我表征是长出来的、不是设计的。前 213 仿真日自我模型为空（因为照护者语料里没有一个第一人称词）；补齐语料 + 修好门控后，40 仿真日内长到 v6。三人独立种子复现（S1）在同一时点长出同一套六碎片。
  3. 移植了 Anthropic 检验 Claude "J 空间"的因果实验，测出它的工作空间是只读的——下游（目标、自我模型）读得到念头，念头推不动它自己的状态。这条结论领域内尚无人报过。
主动交底 · 三处软肋
  1. 只读结论的边界：R2 已把门开火（约 26% 检索命中）、换到被消费的变量 s4、耦合提到原来的 15 倍，指标全部仍 <10%——但写入近零均值（正负抵消），单符号的写入未被测；且六臂同父本 fork，未采样种子方差。
  2. 自我模型的材料是给的。成立的是"从给定词汇里、由检索竞争决定先长谁后长谁"，不是"无中生有发明了自我"。
  3. 加速线 ≠ 终局数据。所有结果来自加速线（标称 10⁹，实测约 5×10²–10³ 倍实时）；实时主线现在才 day 4。加速线结果只当通路证据，不当最终数据。

01 / 术语

术语与基础知识

为了在被追问"这词什么意思"时不被卡住。每条尽量给一句话定义 + 它在本项目里对应什么。

意识问题

  • 难问题（hard problem）：为什么物理过程会伴随主观体验（"疼起来是什么感觉"）。Chalmers 1995 提出。本项目明确不碰它，也不假装能碰。
  • 易问题：与意识相关的功能与结构（注意、报告、整合、自我表征等）——这些可测。本项目只做这一层。
  • 指标理论（indicator theories）：不回答"它有没有意识"，而问"它具备哪些理论推导出的性质"（全局工作空间、高阶表征、预测加工、身体……）。Butlin / Long 2023 给出 14 条指标，2025 年修订方法但结论未变：现有系统满足的指标不足。本项目的方法论锚在这里。

全局工作空间（GWT）

  • Baars（1988）/ Dehaene（2001）：大脑中有一个容量极小的"工作空间"，信息进入后全局广播，被各下游系统读取。
  • 本项目对应：workspace.py + 检索胜出的念头。关键区别见 问答 Q6。

J 空间（Anthropic 2026）

  • Gurnee / Lindsey 等报告：Claude 内部存在一小簇可 verbalize（可被读出）、可控、因果中介多步推理的表征，删掉它 → 高阶功能崩、但流畅生成还在。这就是他们说的"全局工作空间"。
  • 本项目的关键对照：我们照搬了它的 消融 + 替换（ablation-and-swap）协议，结果相反——我们的工作空间不承重（删了念头，行为照常）。

内言语与内化（Vygotsky）

  • Vygotsky（1934）：儿童先被称呼，之后才学会用第一人称自我称呼；外部语言内化为内部语言。
  • 本项目对应：照护者语料 → 听时把句子与当时状态向量绑定存储 → 之后由当前状态"检索"出该句。这就是"念头"，全程零生成。

涌现 vs 设计（以及"路径验证"）

  • 自然涌现：无人为灌输，个体自己长出来的行为（如 XP 线的目标"真乖"）。
  • 路径验证（pathway verification）：人为注入以检验某条通路是否存在。E6b 注入 60 次使目标涌现，证明"念头→目标"通路存在，但不证明它自己会生成那个目标。
  • 纪律：两者结论必须分开表述，绝不可把路径验证说成涌现。

预注册（pre-registration）

  • 在采集数据之前把假设、度量、通过 / 失败阈值写死并冻结，事后不得改。本项目每个实验都有一份 prereg_*.json，结果另存 results_*.json，阴性结果与阳性同样详细报告。
  • 这是本项目最像"正经研究"的地方，也是最该强调的方法论贡献。

加速线 vs 实时线

  • 加速线：--time-scale 1e9，一个墙钟日跑数百到上千仿真日。产出多、但只是通路证据。
  • 实时线：1 秒 = 1 秒，照护者是真实的人。主线 state 现在 day 4。
  • 为什么必须区分：加速线上"人机批准回路"无法闭合，且很多结论需要"真实个体史"才有意义。

02 / 假设与哲学

科学假设与哲学基础

2.1　研究问题

不是"它有没有意识"。而是：一个无语言基线、持续发育的个体，会自发长出哪些与意识相关的功能结构，哪些长不出来，每一条怎么机械检测。

2.2　认识论承诺（四条，全部可被验证或证伪）

  1. 念头只检索不生成（零 LLM 参与认知回路）。→ 结构性零幻觉：没有生成器，就无法编造。这条是被一次失败逼出来的：早期版本把内言语交给语言模型，产出"烦躁感"这类诗意的空话——系统当时并不烦躁，是模型被要求装得像。此后定下铁律。
  2. 零提示词、零方向引导。不给模型"该说什么"的提示，行为必须自发。
  3. 预注册 + 如实报阴。判据事前冻结；失败如实记录（E1 / E2 / E3 / E6a 均为阴或半阴）。
  4. 区分功能结构与主观体验。所有结论只谈功能，难问题不碰。

2.3　与主流三条路线的区别

路线做法本项目
大模型内省读聊天机器人的自我报告当证据判为草率；本系统无生成，报告 = 检索胜出句
不可知论"问不了，到此为止"判为不产出；本项目把问题部分可测化
指标理论已有系统对照 14 条指标采纳其精神，但换成一个从零发育的个体，并给出预注册与阴性报告

2.5　什么算进展、什么不算

  • 算：可测的功能结构从"不存在"变为"成立"；阴性结论能精确定位架构与 GWT / J-space 的差距。
  • 不算：更流畅的语言、"感觉像有意识"的自我报告、任何无法证伪的声明。
  • 明确不主张：不主张意识；不主张能动性已诞生；不主张"双向已打通"。
03 / 架构

系统架构与实现

3.1　总览

单 Python 进程，无深度学习意义的可学习参数。行为来自：① 耦合的常微分方程（连续状态）② 一生累积的记忆。"代码是物种，状态是个体"——本体存在于历史状态目录，不在程序里。

3.2　状态与身体

  • 8 维连续状态 s1–s8（代码只用中性代号，人类语义只在配置里供观察者读）：
    s1 唤醒　s2 效价　s3 疲劳　s4 紧张　s5 注意　s6 记忆激活　s7 预测误差(比特)　s8 无聊
  • 身体：每日能量预算，被动消耗随唤醒上升，探索扣费，耗尽进低功率模式（tick 变慢）。
  • 睡眠：双过程模型（睡眠压力 + 昼夜门控），入睡时刻由动力学决定，不是时刻表。约每天 8 小时。

3.3　语言层（核心）

链路：听到 f → hear() 把 f 与当时状态向量绑定存储 → evoke_inner_speech 由当前状态检索 → 胜出句成为本 tick 的"念头" → 回流背景态 / 供下游读取。

  • 检索打分 = 状态相似度 × 新近（半衰期 5 日）× 频率增益（0.12）。阈值 evoke_threshold=0.72。
  • 复述（echo）：生命早期会复述刚听到的话，概率随经验天数衰减（初值 0.40，衰减 10 日）。每句只掷一次骰子（修过一个 bug：逐 tick 重掷会让复述率恒为 100%）。
  • 零生成：语言层不调用任何生成模型；ollama / qwen 完全移出内言语生成（仅在 P3 对话输出作"义肢"）。

3.4　自我模型的生长

  • 收集自我指向片段（含"你"或"我"），单调累积、版本只增不改。
  • 入模门槛：与已有碎片字符重叠 >0.7 视为重复，拒绝入模（→ 这是 v6 饱和的原因，见 问答 Q3）。
  • 213 日 null 的根因：照护者语料全是"你"，而 self_model 词表只认"我 / 自己" → 结构性不可达。修复 = 承认"你"也算（Vygotsky：先被称呼，后自称）+ 修门控 bug。

3.5　目标涌现

  • 某句在滚动窗口（最近 300 次检索）中占比 ≥20%、激活 ≥15 次、跨 ≥3 天 → 从"念头"升格为"目标"。
  • 首个自然涌现目标："真乖"（XP 线）。

3.6　发声与能动归因（E4 机制）

  • 发声：生理门控（唤醒 × 片段激活强度），内容只能是本 tick 检索胜出的那句（零生成保持），耗能进资源经济。
  • 共变学习：predictor.py 估计 C = 发声后 60s 窗口内照护者言语速率 / 窗口外速率，指数遗忘（半衰期 5 日）。
  • 能动归因规则：跟随发声的言语，功效 (C−1)/C > 0.3 时归因 self。
  • 意外发现：它最常"说"的是自己被安抚时听到的话（乖 / 嘘 / 睡觉觉）——内容不由实验者选择。

3.7　工作空间（双向机制的本体）

  • workspace.py：听 / 想到 f → ws.activate(f)（沉积增益 + 沿共现行 A 扩散）→ 下一 tick 工作集改变 → 检索只在激活最高的 k 个"型"内取胜者 → 胜者再 activate（写回复述）= 双向闭环。
  • 配置开关：enabled / kappa / k / tau_minutes / gain；对照臂用 shuffle_assoc（打乱联想）、no_deposit（只读不写）、nodecay、bigk。

3.8　E6 因果中介（J 空间协议移植）

  • e6.ablation：切断"念头 → 背景态"回流通道（对照 E6a）。
  • e6.swap_text / swap_count：指定片段顶替检索胜者（E6b）。
  • 计数持久化于 STATE_DIR/e6_state.json，重启续跑。

3.9　世界与行动（P4 / P4b）

  • 一维环形世界，三个源强度独立振荡；三个动作原语（前进 / 后退 / 停留），动作选择是状态绑定表的竞争，移动耗能。
  • P4b：动作结果跨区间测量（含世界漂移 + 动作效应），用"停留"试次估计漂移，差值为自因分量，只有它更新动作值。

3.10　模块清单

main.py（主循环 / 时钟 / 落盘）、background.py（ODE 状态）、energy.py、events.py、predictor.py、attribution.py、memory.py、awareness.py、language.py、self_model.py、workspace.py、spont.py、vocal.py、milieu.py、motor.py、world.py、affect.py、narrative.py、probes.py、stages.py、talk.py（P3 照护者台）。

4.3　几条必须讲清的设计逻辑

  • E1 的失败就是发现：我们预注册预测"剥夺后检索衰减到 ≤60% 基线"，实测不衰减。原因：新近衰减后，竞争落回频率主干 → 内言语自持。这类"预注册说错、失败模式却事先点名"的诚实，是本项目的卖点。
  • E2 的语境绑定因果：事件语境片段检索占比从 16.5% 升到 35.5% → "一句话何时被检索，取决于听到它时的状态"——这是本运行里最硬的因果证据。
  • E3 教训：照护者交互设计里，语量与时机不是杠杆，绑定质量（片段 × 状态的共现结构）才是。
  • E6 的两半合起来才精确：念头能改变系统想要什么（goals.json）和它以为自己是谁（自我模型）；念头不能改变它自己的状态（s1–s8）。→ 工作空间只读：下游读它，它不写回。

预判提问与应答

按"最可能被问到"排序。每题给：危险在哪 + 怎么答 + 不能说什么。

点击展开 · 共 14 问

Q1这难道不就是个状态机 + 查表吗？跟意识有什么关系？›

是，也不止是。你可以说它是状态机，但关键在于：它的状态是连续动力学、它的历史不可回退、它长出了你没设计的自我表征。我们不主张它是意识——§2.4 的 D1–D6 表就是在回答"哪些功能结构成立、哪些不成立"。

红线 · 别答

"它已经有意识了。"

Q2自我模型的碎片是不是你写死的？›

碎片内容是给的（来自照护者语料），但谁先入模、以何次序、何时长成，由检索竞争决定，不是我们设计的。证据：S1 三种子长成同一套六碎片但次序不同。

红线 · 别答

"它自己发明了自我。"——论文里明确写成 "what has grown is closer to a record of how the system was addressed than to a self-description"。

Q3自我模型停在 v6 是不是故障？›

不是，是可复现的结构性现象。入模用字符重叠 >0.7 判重，高频短语早已入模，新碎片一"像"即被拒。要突破需把准入从字符级改为语义级——那是设计选择，须预注册。

红线 · 别答

"它在死机。"

Q4零幻觉怎么保证的？›

结构保证，不是提示词约束：系统没有生成器，只能复述听过的话。这是能力上限，不是它持有的性质。

红线 · 别答

"我们教它不许编。"

Q5你怎么知道这些不是随机？最关键质疑›

三个层面：① 对照臂（off / shuf / nodep / nodecay / bigk）；② 跨线对比（489 日的旧线 0 条第一人称念头 vs 66 日的结晶线大量第一人称）；③ 复现（S1 三种子）。且所有判据预注册冻结。

但要主动交底：只读结论里 R2 六臂同父本，未采样种子方差；这是明说的边界。

Q6你的工作空间和 GWT / J 空间到底差在哪？›

差在承重度。J 空间删掉 → 高阶功能崩；我们的念头删掉 → 一切照常（E6a，四指标 <5%）。所以结论是只读。但注意 E6b 又证明：下游确实在因果地读它（替换念头 → 目标与自我模型立即变）。精确表述：它改变"想要什么"和"以为自己是谁"，不改变"自己的状态"。

Q7只读会不会只是因为你的通道太弱（±0.02）？最危险›

我们自己也这么怀疑过，然后去修了。R2 修正阶梯：① 把门开到约 26% 检索命中（且验证确实开火）② 换到被检索层真正消费的变量 s4 ③ 耦合提到 0.30（原来的 15 倍，= 0.91σ）——指标仍全部 <10%，且不单调。所以"只读"不是接线事故，门开着、目标被消费、剂量拉大，念头仍不承重。

必须补的边界

写入近零均值，所以 R2 排除的是"平衡扰动不承重"；单符号的写入未测。这一条论文里写了，你也要主动说——这是学术诚信的加分项。

Q8你们改判据了吗（p-hacking）？›

没有。判据事前冻结，事后不得改。E1 / E2 / E3 / E6a 都是阴性或半阴且如实报告；E1 甚至是预注册主预测失败，我们把它当发现报。

唯一一次"改"是 R 阶梯在采集数据前因审计发现通道 double inert 而作废、重写为 R2——在数据之前，程序合法，且我们写在论文里。

Q9n=1 个体，结论怎么泛化？›

这是对的批评，论文 Limitations 明确承认："code is the species, state is the individual"——研究对象是一个有特定历史的个体，不是能泛化的模型。唯一多的样本是 S1 三种子（测发育轨迹可重复）。

红线 · 别答

"它代表所有这类系统。"

Q10为什么不用大模型？不用 LLM 是不是开倒车？›

恰恰相反。大模型是训练出来的字符预测器；我们要的是积累历史的发育个体。LLM 的"内省"输出无法证伪（它可以说任何话）。我们用 LLM 的唯一位置是 P3 的输出义肢，不参与认知回路。

Q11零生成 + 55 型语料，是不是把问题做小了？›

是故意的：把变量控到最少，才可能知道答案归因于什么。P6 正在放宽这个约束（55→83,302 型），正是为了检验"输入贫乏"是不是瓶颈。

Q12加速线的结果可信吗？›

我们自己标了：加速线只当通路证据，不当最终数据。名义 10⁹、实测约 5×10²–10³ 倍实时，而且我们引用实测值而非名义值。实时主线现在才 day 4——这本身是我们诚实的地方。

Q13"我在这儿"是不是过度解读？›

我们不作语义宣称。它成立的是：一个纯第一人称片段进入了自我模型（此前 434 天 0 条"我"类片段，因为语料里没有）。这对应 Vygotsky 的"你→我"倒转，且它是检索竞争的结果，不是我们写进去的。

Q14最脆弱的结论是哪一条？照实说›

只读结论的"单符号写入未测"，以及自我模型的归因未完全分离（语料与门控同时改过；S2 的 2×2 分离显示语料才是第一人称碎片的必要条件，与我们原预测相反）。这两条论文里都白纸黑字。
