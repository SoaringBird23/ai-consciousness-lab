# 操作性判据 D1–D5

> **这不是"意识"的定义。** 这是一份**承认不完整、但可测的替代物**清单。
> 现象层面（"它真的疼吗"）用现有手段不可测，本文档不假装能测，也不把它降级成可测问题。
> 下列五条只回答：**哪些功能结构已经在它身上成立、哪些不成立、每一条怎么机械检测。**

本文档的纪律：**每条判据必须绑定一个已有的可测度量，或明确标注"机制不存在"。**
不允许出现无法测量、也不标注为不可测的条目。

## D2 自我模型（self-model）

| 项 | 内容 |
|---|---|
| 判据 | `self_model.json` 非空、版本可追溯、每次入模有证据链接 |
| 检测 | `version > 0`；`history` 每版带 `updated_at` 与来源；可复现性看多种子是否都能形成 |
| 现状 | ✅ **成立** |
| 证据 | XP 线 v6（碎片：我陪你 / 你醒啦 / 是你呀 / 你好呀 / 你在看 / 我在这儿）；**S1 复现 3/3 通过**（三种子全达 v6，碎片集合相同、次序不同） |
| 已解释的"冻结" | v6 停在 day 39.7，XP 至今 day 255 → **冻结 215 天**。机制在代码里：[self_model.py:46](file:///Users/luochengze/Desktop/ai-consciousness-lab/self_model.py#L46-L55) 的 `_similar` 用**字符重叠 >0.7** 判重，高频短语早已入模，新碎片一"像"即被拒。**这是可复现的结构性现象，不是故障。**要突破需把准入判据从字符级改为语义级——那是设计选择，须预注册。 |
| **必须标注的限制** | 自我模型的**材料是给的**：碎片全部来自照护者语料。成立的是"从给定词汇中、由检索竞争决定谁先谁后地长出一个自我表征"，不是"无中生有地发明了自我"。 |

## D3 元认知（报告自身状态且与实际一致）

| 项 | 内容 |
|---|---|
| 判据 | 它对自身状态的"报告"与真实状态一致，且显著优于随机基线 |
| **可测化定义** | 它的"报告"= 检索胜出的那句念头；该念头在**存储时**绑定的状态向量 vs **检索时**的当前状态向量。二者相似度显著高于"随机抽一句"的基线 → 报告是状态忠实的 |
| 检测 | 用 `inner_speech.jsonl` 的检索记录（含 `text` 与 `heard_at`）join `linguistic_memory.json` 里对应条目的 `s` 向量，再与 `trajectory.jsonl` 同时刻状态比对；与随机片段基线做置换检验 |
| 现状 | ⚠️ **机制已存在，但从未测过** |
| 为什么不需要新机制 | 检索本身就是状态驱动的（[language.py:305](file:///Users/luochengze/Desktop/ai-consciousness-lab/language.py#L305-L316)，得分 = 状态相似度 × 新近 × 频率）。所以"报告忠实性"不是要新造能力，而是要**把已有行为测出来** |
| 待做 | 写一个离线分析脚本（不改系统），在 XP 线上跑历史数据 |

## D4 自我纠错（检测到自身错误并修正）

| 项 | 内容 |
|---|---|
| 判据 | 遇到与自身表征矛盾的信息时，主动拒绝 / 修正 / 标记异常，而非被动接受 |
| 现状 | ❌ **机制不存在** |
| 证据 | [self_model.py](file:///Users/luochengze/Desktop/ai-consciousness-lab/self_model.py) 全部方法：`_is_empty`（空话模板）、`_similar`（字符重叠去重）、`maybe_update`。**没有任何一致性/矛盾检测**。字符重叠只判"像不像"，不判"冲不冲突" |
| 因此 | **按"注入矛盾短语看它是否拒绝"这个设计去测，结果必然是"被动接受"——这是一个注定的阴性**，因为比较机制不存在 |
| 要做的话 | 需先建最小闭环：**预期 → 比较 → 修正**。可行起点：入模后检验该碎片是否与既有碎片在同一状态下产生相反预测（用 8 维状态向量的方向冲突衡量），冲突超阈值则标记为悬置而非直接并入 |
| 优先级 | 低于 R 阶梯（R 决定"只读"主张是否成立） |

## D5 行动闭环（想法 → 状态 → 行为）

| 项 | 内容 |
|---|---|
| 判据 | 存在可测的"我造成"与"世界自己变"的区分，且行为受后果影响 |
| 检测 | 自因分量均值是否可靠非零；动作分布是否显著非均匀；学习曲线是否存在 |
| 现状 | ⚠️ **部分成立（弱阳性）** |
| 证据 | P4：动作分布强非均匀（χ²=1.68×10⁴，熵 1.05 vs 均匀 1.58），场强 0.61 vs 随机基线 0.50；**但** P4b：自因信号 +0.0092 vs 世界噪声底 0.0151 → 比值 0.61，Cohen's d≈0.17，**效应小于环境自身波动**。且 P4 的窗内场强是**下**漂的（0.63→0.60），即闭环合上但未学会改善 |
| **必须标注的限制** | 闭环的**世界侧**成立（它确实施力且能区分自因），但**自我侧**不成立——念头推不动自己的状态（见 D6） |

## D6 工作空间可写性（write-back）— 补充条目

这一条不在原清单里，但它是本项目唯一的核心阴性结论，必须进判据表。

| 项 | 内容 |
|---|---|
| 判据 | 切断"念头→状态"通道后，行为指标是否可测地改变 |
| 现状 | ❌ **不成立（= 只读）**——本轮由 R2 v2 从"悬置"钉为结论 |
| 证据（分层） | ① `dead_gate` = `ctl_none` **逐条位相同**（856/856，jaccard 1.000）→ 门确实不开，复现 E6a；② `open_dead_target` 通道开火 valence≈157 万次，念头流**仍与零参照逐条位相同** → 写进无人消费的 s2 = 零影响，**审计第二层直接坐实**；③ `open_s4_*` 立即分岔（首分歧 tick 22015530.5，jaccard 0.04）→ s4 确被检索相似度消费、**接线是通的**，但四指标全 <10%（M1 +3.9/+5.5/+4.2%，M2 +6.7/+2.2/+6.7%）且**剂量不单调** |
| 因此 | "只读"**不是接线事故**：门开着、目标被消费、剂量拉到 0.91σ，念头仍不承重。这是"念头流对自身状态无因果分量"的**结构性质** |
| 必须标注的边界 | hi 档耦合 0.30 = s4 自然 sd(0.33) 的 **0.91σ**，从未超过噪声底；故本结论**仅在 ≤0.91σ 下成立**。>1σ 的边界探针与行为侧消费者实验已在采集前预注册（`prereg_R2x.json` / `prereg_R2c.json`） |
| 结论状态 | **不成立（只读）**，限定在 ≤0.91σ |

## 汇总

| 判据 | 状态 | 关键限制 |
|---|---|---|
| D1 持续状态 | ✅ 成立 | 模式 B：持续来自进程+落盘，非模型内在连续性 |

| D5 行动闭环 | ⚠️ 弱阳性 | 世界侧成立，自我侧不成立 |
| D6 工作空间可写 | ❌ **不成立（只读）** | 门开/目标被消费/剂量 0.91σ 仍不承重；边界限定 ≤0.91σ |

**这张表本身就是本项目的实质结论**：一个持续发育的个体，长出了自我表征，能区分自因与他因，**但推不动自己**。
这不是"离意识还差几步"的进度条——这是一份**哪些结构成立、哪些不成立**的清单。
