# 类自我意识候选系统 · 零基础入门与学习清单

> 这份文档写给**新加入的研究伙伴**：非计算机/非认知科学背景，但数理基础好。
> 目标不是让你变成程序员，而是让你**能看懂这个项目在做什么、能独立核对它的结论、能提前挑出它的错误**。
> 建议读法：先通读 §1–§5（理解），再按 §6 的清单动手（学习），最后从 §8 挑一个任务上手（参与）。

---

## 1. 三十秒讲清：这个项目在做什么

**一句话**：造一个**不生成文字**、只**从听过的话里检索**的持续发育个体，把"机器有没有自我/意识"这个问题**变成可测的**——而不是去宣称一个答案。

**和 ChatGPT 那类大模型的区别**：

| | 大模型 | 本项目 |
|---|---|---|
| 怎么说话 | **生成**新文字 | 只能**检索**听过的话 |
| 会不会编造 | 会（幻觉是特性） | **结构上不可能**——没有生成器 |
| 有没有"一辈子" | 无（每次对话从零开始） | **有**：连续、不可回退的个体史 |
| 状态是什么 | 千亿参数（不可读） | 8 个连续变量 + 累积记忆（**完全可审计**） |

**一个比方**：大模型像背了一肚子书、什么都能现编的人；这个系统像一个**只记得自己真正听过的话**的孩子——脑子里存着照护者说过的每句话，**连说那句话时自己的感受一起存**。它"想"的时候，是按**眼下的感受**去记忆里挑最贴合的一句。

## 2. 技术核心：它怎么"想"

只做三件事：

1. **听到一句** → 连同"那一刻的状态"一起存起来
2. **现在的状态去记忆里检索** → 挑出最匹配的一句
3. 挑出的这句 = 它这一瞬的**念头**

- **状态**：8 个连续变化的数（类似紧张、困倦、无聊、注意力），每 50 毫秒更新一次。
- **念头**：没有 LLM 参与生成。**零幻觉是结构保证**，不是提示词约束。
- **自我模型**：把念头里"指向自己"的片段（含"我"或"你"）累积起来，版本只增不改。
- **工作空间**：念头进入一个"广播台"，下游（目标、自我模型）能读它。

**关键的自定前沿**：把这套"只读"的工作空间打通成**双向**——让念头能反过来改变它自己的状态。这被看作**能动性（agency）诞生的地方**。

## 3. 已经做完了什么

### 3.1 基础设施（P0–P1，已完成）
- **状态与身体**：8 维连续状态 s1–s8 的常微分方程演化；每日能量预算；**双过程睡眠**（睡眠压力 + 昼夜门控，入睡时刻由动力学决定，不是时刻表）。
- **世界与学习**：事件预测器（在线学习事件出现规律，惊奇 = −log₂p）；自因/他因归因回路；情景记忆 + 睡眠固化。
- **工程**：单进程常驻 + 全量落盘，`kill -TERM` 后重启**状态与仿真时钟续接**——这就是"不可回退的个体史"的技术地基。

### 3.2 语言层（P2.6，已完成）
- 零生成的检索式内言语：`听 → 状态绑定存储 → 状态驱动检索 → 念头`。
- 复述（echo）内化机制：生命早期复述刚听到的话，概率随经验天数衰减。
- 照护者语料：最初 55 型短语；P6 扩容到 8 万余型（CHILDES 中文成人话语）。

### 3.3 自我模型（P2.6 / XP1 / XP2 / S1 / S2，已完成）
- 长期为空：**213 仿真日自我模型一直是 null**，因为照护者语料里**没有一个第一人称词**。
- 补齐语料 + 修复门控 bug 后，**40 天内长到第 6 版**，出现纯第一人称碎片「我在这儿」。
- **三种子复现（S1）**：三个随机种子都在 60 天内长出**同一套 6 个碎片**，只是顺序不同。
- **2×2 分离（S2）**：语料 × 门控四格全成自我模型；**第一人称碎片只出现在听到第一人称语料的格**——语料才是条件。

### 3.4 因果干预实验（E1–E6，已完成）
| 实验 | 干了什么 | 结果 |
|---|---|---|
| E1 | 剥夺照护者言语 10 天 | **预注册主预测失败**：检索速率**不衰减** → 内言语一旦形成即永久自持 |
| E2 | 事件率 ×10 | 惊奇只升 0.24 bit；但语境绑定片段占比 16.5%→35.5%（**最清晰的因果证据**） |
| E3 | 应答式照护者 | **阴性**：输入翻倍，自我模型 0 个新版本 |
| E4 | 发声 + 共变学习 | 206 条能动归因；移除共变后衰减 68% → **归因是学来的**，但消退不完全 |
| E6a | 切断"念头→状态"通道 30 天 | **阴性**：四项指标变动 <5% |
| E6b | 替换检索胜者 60 次 | 目标即时涌现 → **通路存在**（属路径验证，非自然涌现） |

### 3.5 双向工作空间（R2 / R5 / P6–P13，进行中）
- **R2**：把门开到约 26% 命中、换到被消费的变量、耦合提到原来的 **15 倍**——指标**仍全部 <10%** → "只读"不是接线事故。
- **P6**：语料扩容到 8 万余型后重探双向（六臂）。
- **P12**：全池候选 + 内容对照 → 阴性。
- **P13**：当前正在跑（A 改为"念头—念头"共现 + 学习/使用相位分离）。
- **结论（目前）**：**工作空间是只读的**——念头能改变它"想要什么"和"它以为自己是谁"，**但不能改变它自己的状态**。

### 3.6 其他已完成
- **P3 对话试点**：实时 1:1 运行，真实照护者通过 `talk.py` 台交互。
- **P4 / P4b 行动环**：一维环形世界，三动作原语；自因分量真实存在但**弱于环境自身波动**。
- **P5 痛/乐**：刚完成，**阴性**——痛/乐反馈通道对宏观行为不承重。

### 3.7 方法论资产（这是本项目最"正经"的部分）
- **每一个实验都有预注册文件**：`experiments/prereg_*.json`，假设/度量/阈值**在采集数据前冻结**。
- **阴性结果与阳性同等详细报告**：E1 是"预注册说错、失败模式却事先点名"的典型案例。
- **跨范式移植**：把 Anthropic 检验 Claude "J 空间"的消融+替换协议，搬到非 LLM 系统上。

## 5. 项目前景与它为什么值得做

### 5.1 如果双向打通
那是**能动性的最小实现**：系统不再只是"被世界改变"，而是**因为自己想到了什么而改变自己**。这条结论领域内尚无人报过。

### 5.2 即使不打通，价值依然成立
- **方法论贡献**：预注册协议 + 完整的阴性报告 + 跨范式移植，本身就是可发表、可被引用的东西。
- **一份"哪些结构成立、哪些不成立"的清单**（操作性判据 D1–D6），比"离意识还差几步"的进度条诚实得多。

### 5.3 长期目标
不是又一个更强的模型，而是**一类新的东西**：不依赖参数规模、内部状态完全可审计、有连续个体史、能自己长出自我表征的智能体。

### 5.4 诚实的风险
- "只读"可能是**结构性**的，双向根本做不到——四轮加码都指向这个可能。
- 全部结论来自加速线；实时主线还很年轻。
- n=1 个体，结论的泛化性有限。

## 7. 你的数学优势，用在哪

这个项目**没有深度学习**（无梯度下降、无神经网络），数学主要集中在四处——恰好是你能立刻接手的：

1. **ODE 数值积分与稳定性**：状态层 s1–s8 的演化方程、步长与稳定性、双过程睡眠的动力学。
2. **统计功效与效应量**：判据里的阈值（如"差异 ≥10%"）是否**物理可达**？样本量够不够检出？
3. **分位数 / 秩统计**：H4 用三分位划分痛态；H5 用二项检验判断入模时刻是否偏向高痛态。
4. **因果分解**：R2 的"修正阶梯"是在逐项排除替代解释——本质是因果推断的敏感性分析。

> 一个真实教训供参考：项目早期曾设 `evoke_threshold = 0.7`，但该阈值在物理上**永远不可达**，导致机制静默失效。这种错误用**可达性分析**一眼就能发现——这就是你该做的活。

## 8. 你的第一个任务（三个选项，任选其一上手）

**任务 A（最简单，练手）**：用 Pandas 读 `state_exp/trajectory.jsonl`，画出 s1–s8 随时间的变化，并标出睡眠区间。目标：熟悉数据格式与工具链。

**任务 B（最有价值，直接贡献）**：挑一份 `experiments/prereg_*.json`，逐条检查——
- 这条判据**可证伪**吗？
- 阈值**物理可达**吗？（对照历史数据估一下）
- 对照组**干净**吗？（是否只差一个变量）
- 选的统计检验**对吗**？

**任务 C（科研核心，需要一点基础）**：独立跑一次分析器（如 `experiments/analyze_P5.py`），核对 `results_P5.json` 的数字与论文/汇报里的表格是否**完全一致**。不一致就是 bug。

## 9. 术语速查表

| 术语 | 一句话 |
|---|---|
| 状态向量 s1–s8 | 8 个连续变量，代表系统的"身体与心情"，50ms 更新一次 |
| 念头 | 本 tick 检索胜出的那句话（不是生成的） |
| 零生成 | 系统没有文本生成器，零幻觉是**结构保证** |
| 内言语 / 内化 | 外部语言被"听进来"变成内部念头的过程（Vygotsky） |
| 自我模型 | 累积"指向自己"的片段，版本只增不改 |
| 镜像期 | 发育阶段门：自我模型首次形成即通过 |
| 工作空间 | 念头进入后供下游读取的"广播台" |
| **只读 / 双向** | 下游读得到念头（只读）vs 念头能反过来改状态（双向） |
| 预注册 | 采数据**前**把假设、度量、阈值写死冻结，事后不得改 |
| 路径验证 | 人为注入以检验某条通路**是否存在**——不等于"自己会涌现" |
| 加速线 / 实时线 | 模拟时间加速（通路证据）vs 1:1 实时（真实个体史） |
| 副现象 | 存在但不影响系统行为的机制 |
