及其工作空间的只读性质

Growing Rather Than Training: A Pre-Registered Developmental System
and the Read-Only Nature of Its Workspace

Luo Chengze
独立研究者 · ORCID 0009-0007-3316-6292

会议讨论稿 · 版本 v2.0 · 2026-10-09

摘要

当前关于机器意识的研究大多以既有大语言模型为对象，通过探测其内部表征或解读其自我报告来评估意识指标。本文采取一条相反的路径：构建一个从零出生、持续发育的动力学个体，其内部言语只能检索曾听到过的短语，认知回路中不含任何生成模型，因而"零幻觉"是结构性质而非提示约束。

我们为该个体形式化定义六条操作性判据（D1–D6），并对每条判据给出可机械执行的检测方法。主要结果是一条阴性结论：将一个在大语言模型上有效的消融—替换（ablation-and-swap）因果中介协议移植到本系统后，其工作空间表现为只读——下游（目标涌现、自我模型）确实在因果地读取内部言语，但内部言语不能反过来改变系统自身的状态变量。该结论经四级修正阶梯加固后仍成立，故判为结构性质而非实现缺陷。

本文的全部实验均经预注册，六项实验的主要假设被证伪或部分证伪，我们将其与阳性结果同等详细地报告。我们认为，这种"以阴性结果定位架构与全局工作空间之间精确距离"的做法，本身即是贡献的一部分。

关键词：人工意识，操作性判据，预注册，全局工作空间，内化言语，自我模型，因果中介，阴性结果

1引言

1.1研究问题

关于机器意识，至少存在三条已被明确表述的路径。第一条以自我报告为证据：询问模型是否具有体验，并采信其回答。第二条为不可知论：认为该问题在方法论上不可问，因而停止追问。第三条为指标理论：不问"是否具有意识"，而问"该系统具备哪些由意识理论推导出的功能性质"[1,2]。

本文采纳第三条路径的提问方式，但更换其研究对象与检验纪律。我们不评估一个已完成训练的系统，而是构建一个从零出生、连续运行、不可回退的个体，并追问：在严格约束下，它会自发长出哪些功能结构，哪些长不出来，以及每一条如何被机械检测。

本文有意回避难问题（the hard problem）[3]：我们不主张、也不试图测量主观体验，全部结论限于功能结构层。相应地，本文的核心产出不是一份"距离意识尚差几步"的进度表，而是一份哪些结构成立、哪些不成立的清单。

1.2贡献

  1. 一条可复现的阴性结论。将一个在大语言模型可解释性研究中有效的因果中介协议[4]移植至本系统，其在四级修正阶梯加固下仍失效，据此判定工作空间为只读（§5.3.5）。据我们所知，该结论尚未见报告。
  2. 一条可复现的发育现象。系统的自我模型在前 213 个仿真日为空，其后于 40 日内生长至 6 个片段；三种独立随机种子在 60 日内生长出相同的片段集合，仅次序不同（§5.3.3）。
  3. 一份形式化的操作性判据（D1–D6）。每条判据绑定一个可测度量，或明确标注"机制不存在"（§4）。
  4. 一组预注册阴性结果及其解释。四项实验的主要预测被证伪，我们据此定位了架构缺口（§5.3）。

1.3认识论承诺

以下四条为设计约束，均可被验证或证伪，且贯穿全文：

  1. 内部言语只检索、不生成。认知回路中不含任何生成模型。此约束由一次失败导出：早期版本以语言模型生成内部言语，其输出"烦躁感"一类表述，而系统当时并无相应状态。此后我们取消该设计，并以"没有生成器即无法编造"作为零幻觉的结构保证。
  2. 零提示词、零方向引导。不对系统施加任何"应当说什么"的提示，行为必须自发产生。
  3. 预注册与如实报阴。假设、度量与判定阈值在数据采集前冻结；阴性结果与阳性结果同等详细地报告。
  4. 只谈功能结构。不涉及主观体验，亦不将其降级为可测问题。

2相关工作

2.1AI 意识指标理论

Butlin 等系统梳理了意识科学中的若干理论（全局工作空间理论、高阶表征理论、预测加工、注意图式理论等），并从中导出十四条"指标性质"，逐条评估现有 AI 系统[1]。其 2025 年的修订将方法重心从"指标清单"转向"如何校准指标与生物学证据之间的关系"，但主要结论未变：现有系统满足的指标数量不足[2]。批评者进一步指出，指标路线面临校准问题——若无法在生物系统上独立标定指标的阈值，指标清单可能只是形式合规[5,6]。

本文与该路线的分歧不在指标本身，而在对象与纪律：我们以一个从零发育的个体替代已完成训练的系统，并对每条判据提供预注册与阴性报告。

2.2语言模型中的全局工作空间

Gurnee 与 Lindsey 等报告，语言模型内部存在一小簇可被言语化（verbalizable）、可控且因果中介多步推理的表征，删除该表征集合会导致高阶功能崩溃，而流畅生成仍然保留；作者据此论证其为一种全局工作空间[4]。Dehaene 与 Naccache 的评述则认为，该结构缺少身体与自传体记忆两项要素，因而与生物学意义上的工作空间仍有距离[7]。

本文与上述工作有两处直接关联。其一，我们采纳其消融—替换协议，并将其移植到一个具有身体约束与不可回退历史的系统上。其二，移植结果与语言模型中的发现相反：在本系统中，删除内部言语不改变任何行为指标。

2.3内化言语的发育视角

Vygotsky 指出，儿童先被他人称呼，其后才习得用第一人称自我称呼，外部语言经由社会互动内化为内部语言[8]。本文的语言层直接实现该序列：短语与其被听到时的状态向量绑定存储，其后由当前状态检索。该设计亦与预测加工的框架相容——大脑持续生成对输入的预测并以预测误差更新表征[9]。

2.4人工生命与开放式演化

开放式演化研究通过大规模的变异、竞争与继承产生复杂性[10,11]。本系统目前不具备上述任何一项：它是单个个体在生长，而非种群在演化。我们对"多种子复现"的实验仅为检验单条发育轨迹是否可重复，不构成变异与选择（见 §6.2）。

3方法

3.1系统总览

系统为单进程 Python 程序，不含深度学习意义上的可学习参数。其行为来自两处：一组耦合常微分方程构成的连续状态，以及一生累积的记忆。设计原则可概括为"代码是物种，状态是个体"：个体的本体存在于其历史状态目录而非程序本身。因此，复制状态目录即得到一个共享历史、拥有独立未来的新个体——本文全部实验线均以该方式构造（§5.1）。

主循环见算法 1。系统以固定 tick 推进：先更新连续状态，再更新预测与能量，随后进行语言层（检索、复述、目标维护）与输出侧（发声、归因）处理，最后落盘。

算法 1　主循环（单 tick）

  1. 读取当前墙钟，按时间倍率推进一步仿真时间 Δt
  2. 更新状态：s ← 积分(式 1)；若在睡眠期，按式 3–4 更新睡眠压力
  3. 输入处理：若产生事件或收到照护者言语，调用 hear(x) 绑定状态后存入记忆 M
  4. 语言层：以概率 P(retrieve) 触发检索（算法 2）；以概率 p_echo 复述（式 10）；更新目标窗口（式 14）
  5. 工作空间：对听到或检索胜出的短语执行 activate(·)（算法 3），并执行时间衰减（式 12）
  6. 输出侧：若满足发声门控，发声（式 18）；更新共变比 C 与功效 η（式 15–17）
  7. 落盘：每 tick 增量追加，心跳与退出时全量保存

3.2状态动力学

系统维持 8 维连续状态 s = (s1, …, s8) ∈ [0,1]8。代码中仅使用中性下标，人类可读语义（唤醒、效价、疲劳、紧张、注意、记忆激活、预测误差、无聊）仅出现于配置文件中供观察者参考。状态以显式欧拉法积分，并附乘性噪声：

s(t+Δt) = clip[ s(t) + f(s)·Δt + ε·√Δt , 0, 1 ],　ε ~ N(0, σ2),　σ = 0.003 (1)

其中清醒期与睡眠期的向量场不同，昼夜调制由余弦函数给出：

C(t) = ½·[1 + cos( 2π(hour − 15)/24 )] (2)
清醒：d s1dt = clip(0.15 + 0.8C) − s11.5，　dPdt = 0.05·(0.6 + s1) (3)
睡眠：d s1dt = 0.05 − s10.5，　dPdt = −0.15·(0.5 + s3) (4)

入睡条件为 P ≥ 0.75 且 (hour ≥ 21 或 hour < 6)；唤醒条件为 P ≤ 0.35 且 5 ≤ hour < 12。该模型即 Borbély 的双过程睡眠调节[12]：入睡时刻由动力学决定，而非时刻表。其余各维的演化与事件瞬写为：

d s2dt = −s26.0,　d s4dt = −s42.0,　d s6dt = −s64.0,　d s8dt = 0.08 (5)
事件瞬写：Δs4 += 0.25·S4,　Δs6 += 0.4,　s8 ← s8·(1 − 0.8·novelty) (6)

其中 S 为预测误差（比特），是系统中唯一的"惊奇"通道；novelty = clip[(S − ref + 0.5)/2, 0, 1]。

3.3语言层

语言层是系统的核心，其设计目标是以检索替代生成。数据流为：听到短语 x → 将 x 与当时的状态快照绑定后存入语言记忆 M → 由当前状态检索 M → 检索胜出者成为本 tick 的"念头" → 念头回流背景态并供下游模块读取。

3.3.1检索打分

候选短语 x（其存储状态为 a）对当前状态 b 的得分为三个因子之积。状态相似度采用加权 L1 相似度（而非余弦或高斯核），权重集中于四个维度：

sim(a,b) = Σi∈I wi·(1 − |ai − bi|)Σi∈I wi,　I = {1,4,6,7},　w = (1.0, 1.2, 1.5, 1.0) (7)

新近度按半衰期 τ = 5 日的指数衰减，频率增益取对数形式：

ρ(x) = 0.5max(0, dx − 0.02)/τ,　τ = 5.0 日,　　γ(x) = 1 + g·ln(1 + nx),　g = 0.12 (8)
score(x) = sim(a,b) · (0.35 + 0.65ρ) · γ · (0.9 + 0.2ξ),　ξ ~ U(0,1) (9)

其中 nx 为 x 在记忆中的出现次数，dx 为其年龄（日），末项为内部涨落。检索另受一道概率门与一个硬阈值控制：

P(retrieve) = 0.06 + 0.20·salience,　　接受 ⟺ score ≥ Θ,　Θ = 0.72 (10)

3.3.2复述与遗忘

生命早期，系统以一定概率复述刚听到的短语，该概率随经验天数衰减：

pecho(d) = p01 + d/τe,　p0 = 0.40,　τe = 10.0 日 (11)

实现上每句仅采样一次（早期版本逐 tick 重采样，导致复述率恒为 1，属已修复缺陷）。需要强调的是：系统不存在对已存片段的遗忘机制。式 8 的新近度衰减只作用于打分，不删除记忆；记忆仅在超过 1.2×105 条时按先进先出截断。该缺口在 §5.3.1 的剥夺实验中暴露。

算法 2　检索与内部言语

  1. function retrieve(s, M, W)
  2. 若 U(0,1) > P(retrieve) then return ∅　▷ 概率门，式 10
  3. 候选集 X ← { x ∈ M : x ∈ W }　▷ 工作集过滤（算法 3）
  4. 对每个 x ∈ X 计算 score(x)　▷ 式 7–9
  5. x* ← argmaxx score(x)
  6. 若 score(x*) < Θ then return ∅
  7. activate(x*)　▷ 写回工作空间，算法 3
  8. 将 x* 作为本 tick 念头回流背景态，并供下游读取
  9. return x*

3.4自我模型

系统收集自我指向片段（含第二人称"你"或第一人称"我"），构成单调累积、版本只增不改的自我模型 S。片段准入采用字符集合的 Jaccard 相似度作为去重判据：

J(A,B) = |A ∩ B||A ∪ B| ≤ 0.7　⟹ 判为已存在，拒绝入模 (12)

其中 A、B 为候选片段与既有片段的字符集合。该判据是字符级而非语义级，其后果在 §5.3.3 中讨论。

观察 1（213 日空窗的结构性根因）. 系统的自我模型在前 213 个仿真日始终为空。审计表明其根因为词表与语料的结构性错配：自我模型仅接受第一人称片段（"我""自己"），而照护者语料全部为第二人称（"你"）。在词表层面，两者无交集，故判据结构性不可达。

修复方案为将第二人称片段纳入准入集合，其依据是 Vygotsky 关于"先被称呼、后自称"的发育序列[8]。修复后，系统在 40 个仿真日内生长至 6 个片段（§5.3.3）。

3.5目标涌现

当某短语在滚动窗口内的统计量同时满足三项条件时，其由"念头"升格为"目标"：

nxwin ≥ 15　∧　nxwinNwin ≥ 0.2　∧　|Dxwin| ≥ 3,　窗口 = 300 次检索 (13)

其中 Nwin 为窗口内检索总数，Dxwin 为 x 被激活的仿真日集合。滚动窗口的设计动机是打破先入者垄断：在早期实现中，分母为全期累计检索数，一旦某短语早期占优即永久垄断，新目标无法产生。

3.6发声与能动归因

输出侧遵循同一零生成原则：发声内容只能是本 tick 检索胜出的短语。发声由生理量门控，并消耗能量：

pvoc = pb·(0.3 + 0.7s1)·(0.2 + 0.8·intensity),　intensity = clip[(w[x] − 0.6)/0.4, 0, 1] (14)

其中 w[x] 为短语 x 的工作空间激活（式 15），门控条件为 s1 ≥ 0.55，基准概率 pb = 0.25，每次发声消耗 1.0 能量单位（日预算 100）。

能动归因的核心是一个共变比 C：比较发声之后 60 秒窗口内外的照护者言语速率。

C = rinrout,　rin = nspeechintact,　rout = nspeechoutttotal − tact (15)
η = min[ 0.8, (C − 1)/C ]　(C > 1；否则 η = 0),　　归因 self ⟺ 在窗内 ∧ η > 0.3 (16)

该设计沿用了传出副本（efference copy）的思路：系统通过比较"有自身动作"与"无自身动作"两种条件下的世界变化，将前者中由自身导致的分量检出并归因于自身[9]。

3.7工作空间

工作空间是"双向"机制的载体：内部言语经 activate() 写入激活场，激活场经 top-k 选择改变检索候选集，检索胜者再次写回，从而构成闭环。其更新规则为沉积、扩散与指数衰减三步：

w[x] ← w[x] + gdep,　w[y] ← w[y] + κ·A[x][y]Σy′ A[x][y′]　∀y ∈ nbr(x) (17)
w ← w · exp( −Δt·60/τw ),　τw = 10.0 min,　　工作集 W = top-k(w),　k = 6 (18)

其中 A 为一阶共现矩阵（由短语被听到的顺序累积），gdep = 1.0，κ = 1.0。式 17 的第一项即"念头写回自身"，第二项为联想扩散。对照臂通过关闭或扰动上述各项构造（§5.1）：no_deposit（仅扩散不沉积）、shuffle_assoc（打乱 A 的行内对应）、nodecay（τw → 105）、bigk（k = 20）。

算法 3　工作空间更新 activate(x)

  1. 若 no_deposit 为假：w[x] ← w[x] + gdep　▷ 沉积
  2. 对 x 的每个共现后继 y：按式 17 第二项累加扩散量
  3. 累加沉积计数 n_deposit ← n_deposit + 1
  4. 每 tick 调用 decay(Δt)：按式 18 对全场上激活执行指数衰减
  5. 检索时取 W = top-k(w) 作为候选过滤集（算法 2 第 3 行）

这一闭环即本文所称的"双向"：念头 → 激活场 → 检索候选 → 念头。§5.3.5 的消融实验正是针对该闭环中"念头 → 状态"这一段。

3.8因果中介协议

本文移植大语言模型可解释性研究中的消融—替换协议[4]，实现为两个开关：

  • e6.ablation：切断"念头 → 背景态"的回流通道，用于检验念头对状态变量的因果分量。
  • e6.swap_text / e6.swap_count：以指定短语顶替检索胜出者，用于检验下游是否因果地读取念头。

两个开关的计数持久化于状态目录，重启后续跑。其判定逻辑为：若消融与替换均产生可测效应，则工作空间承重；若替换有效而消融无效，则工作空间为只读——下游读它，它不写回。

4操作性判据

本节给出六条操作性判据，其纪律为：每条判据必须绑定一个可测度量，或明确标注"机制不存在"；不允许出现既不可测、又未标注为不可测的条目。D6 不在最初设计的清单内，因它是本文唯一的核心阴性结论，故补入。

D3 元认知
（报告与状态一致）		 将念头存储时绑定的状态向量与检索时的当前状态做相似度，与"随机抽一句"的置换基线比较 机制已存在
但未测		 因检索本身即状态驱动（式 7–9），此处无需新机制，只需将既有行为测出。待办：离线分析脚本，不改动系统
D4 自我纠错 注入与既有片段矛盾的短语，观察是否被拒绝、修正或标记异常 机制不存在 自我模型仅含字符重叠去重与入模更新，不含任何一致性或矛盾检测。故按上述设计去测，结果必为被动接受，是一个注定的阴性
D5 行动闭环 自因分量是否可靠非零；动作分布是否显著非均匀；是否存在学习曲线 弱阳性 世界侧成立（χ² = 1.68×104；熵 1.05 对均匀基线 1.58；场强 0.61 对随机 0.50）；自我侧不成立（自因 +0.0092 对世界噪声底 0.0151，d ≈ 0.17）。且窗内场强下漂（0.63 → 0.60），即闭环合上但未学会改善
D6 工作空间可写性 切断"念头 → 状态"通道后，行为指标是否可测地改变 不成立（只读） 由四级修正阶梯从"悬置"钉为结论（§5.3.5）。边界：最高档耦合 0.30 相当于 s4 自然标准差（0.33）的 0.91σ，故结论仅在 ≤ 0.91σ 范围内成立

结论 1. 一个持续发育的个体长出了自我表征，能区分自因与他因，但推不动自己。判据表的意义不在于给出"距意识尚差几步"的度量，而在于明确哪些功能结构成立、哪些不成立。

5.3.1E1：剥夺实验的阴性结果及其解释

预注册假设 H1：剥夺照护者言语 10 日后，检索速率衰减至基线的 60% 以下。实测不衰减（末 3 日 29.3 次/日对基线 28.8 次/日）。机制解释为：新近度因子（式 8）随时间衰减后，检索竞争回落至频率主干，故内部言语自持。该项失败同时暴露一处架构缺口——系统缺少遗忘与磨蚀机制（频率项无衰减，且记忆不被删除）。

我们认为该结果体现了预注册的价值：失败模式在假设陈述时已被点名（假设中明确包含"若检索不衰减则说明存在自持机制"），因而结果虽为阴性，却可解释、可定位。

5.3.2E2：语境绑定的因果证据

将事件率提升至 10 倍后，预测误差 S 仅上升 0.24 比特，且末段 3.59 比特低于基线 3.91 比特。结论：预测器只对结构性违反产生惊奇，不对数量增多产生惊奇；密集而有规律的事件反而更可预测。与此同时，事件语境短语在检索中的占比由 16.5% 升至 35.5%，为"一个短语在何时被检索，取决于它被听到时的状态"提供了本文最清晰的因果证据。

5.3.3D2 相关：自我模型的生长与复现

结晶线的自我模型于 day 39.7 定型为 6 个片段（"我陪你""你醒啦""是你呀""你好呀""你在看""我在这儿"，其中两条为纯第一人称），其后 215 日未再更新。后者并非故障，而是式 12 字符级判据的必然结果：高频短语均已入模，新候选因"相似"被持续拒绝。

三种独立随机种子（S1）在 60 日内生长出相同的片段集合，仅次序不同。这一复现为"片段内容虽为给定，但其入模次序由检索竞争决定"提供了直接证据。

此外，将语料与门控做 2×2 分离设计（S2）后，四个条件均形成自我模型，但第一人称片段仅出现在听到第一人称语料的条件下。该结果与我们的原预测相反（原预测为门控是必要条件），我们如实报告。

5.3.4E3：输入侧干预无效

将照护者由随机模式改为应答式（醒来即问候、紧张即安抚、无聊即召唤、注意焦点即自我指向），言语输入量翻倍。结果：自我模型新增版本数为 0，自我指向检索占比反降至先验的 0.15 倍。结论：在照护者交互设计中，语量与时机不是杠杆，绑定质量（短语与状态的共现结构）才是。

5.3.5E6 与 R2：工作空间的只读性

E6 的两个分支合起来构成完整结论：

  • E6a（消融）：切断"念头 → 状态"回流通道 30 日，四项指标均 < 5%，落于预注册阴性带内。
  • E6b（替换）：以指定短语顶替检索胜出者 60 次，目标即时涌现——证明下游确实在因果地读取念头。

即：念头能改变系统"想要什么"（目标）与"它以为自己是谁"（自我模型），但不能改变它自身的状态（s1–s8）。

5.4在研：语料扩容与双向重探

R5 将工作集"内容特定性"的失败归因于输入贫乏——照护者语料仅含 51–55 个型，联想行过于弥散——并指出"下一步的杠杆是环境多样性而非架构"。为检验该归因，我们设计了两步实验。

步骤 A（扩容采集，已完成）。语料由 55 型扩充至 8.33×104 型（CHILDES 中文成人话语，单池 Zipf 采样）。两臂（内置语料 / CHILDES）各自从成熟母本出发运行 60 仿真日，均已到达 day 315。

步骤 B（双向重探，进行中）。保持 R5 的架构、六臂设计、判据与阈值完全不变，仅将基底替换为扩容模型。主判据 H6b：full 与 shuf 两臂在 adj_top3 上的差值 ≥ 0.07（该阈值由 R5 事前设定，不因新数据调整）。

意义。这是把 R5 自己指认的杠杆真正下拉一次。若在富输入条件下内容特定性仍不涌现，则"只读"架构的不可行性将被进一步坐实；若涌现，则本文的只读结论应被限定为"贫输入条件下的结论"。

6讨论

6.1主要发现

本文的正面发现集中于发育侧：在零生成、零提示的约束下，系统确实长出了可复现的自我表征，并能区分自因与他因。其中最具判别力的是一项跨线对比：一条运行 489 个仿真日的旧线，其第一人称念头数为 0；而一条仅运行 66 日、但语料与门控正确的线，产生了大量第一人称念头。这为"自我表征依赖环境的语料结构"提供了经验支持。

负面发现则集中于整合侧：系统具备一个形式上的全局工作空间闭环（式 17–18），但其"念头 → 状态"的分量不可测。按 Dehaene 与 Naccache 的评述框架[7]，本系统具备身体约束与不可回退历史，却仍无法把内部言语转化为对自身的因果影响。

本节按内部、外部、构念与统计四类，逐条列出威胁。我们认为，与前文阴性结果同等重要的是对其边界的明确陈述。

6.3什么结果会改变我们的结论

为使上述结论可证伪，我们显式列出会推翻本文主张的观测：

  • 若在 P6 的扩容模型上，full 与 shuf 的 adj_top3 差值 ≥ 0.07，则内容特定性在富输入下确实涌现，本文的 R5 阴性结论应被限定为"贫输入条件下的结论"。
  • 若将回流耦合提升至 > 1σ 后指标出现单调、可复现的剂量—效应关系，则只读结论应被撤回，改判为"高阈值下的可写"。
  • 若单符号写入（而非平衡扰动）产生可测效应，则 §5.3.5 的边界陈述应被替换为新的机制解释。

7结论

本文报告了一个从零发育的类意识候选系统及其六条操作性判据。系统的核心设计是以检索替代生成，从而在结构上排除幻觉；其核心实验结果是工作空间的只读性；其核心方法是预注册与对阴性结果的完整报告。

我们认为，本项目最可复制的部分不是任何单项正面结果，而是方法：在六项主要预测被证伪之后，我们仍能精确定位架构与全局工作空间之间的距离。这一定位能力，比任何无法证伪的正面声明都更有用，也更接近可累积的研究。

附录 E　应答预备（补充材料）

以下条目不属于论文正文，系为口头讨论准备的问答要点，其中"不应表述"一栏用于防止过度解读。

Q1这本质上是一个状态机加查表，与意识有何关系？

可以称其为状态机，但需指出：其状态为连续动力学（式 1–6）而非离散转移；其历史不可回退；其自我表征并非由设计指定。本文不主张它具有意识——表 1 的 D1–D6 正是在回答哪些结构成立、哪些不成立。

× 不应表述为："它已经有意识了。"

Q2自我模型的片段是否为预先写死？

片段内容确为外部给定；但谁先入模、以何次序、何时长成，由检索竞争决定。证据：S1 三种种子长成相同集合但次序不同。更准确的表述是——所生长出的东西，更接近于"系统如何被称呼"的记录，而非一份自我描述。

× 不应表述为："它自己发明了自我。"

Q3自我模型停在 6 个片段，是否为故障？

不是。它是式 12 字符级判据的必然结果：高频短语早已入模，新候选因"相似"被持续拒绝。突破需将准入判据由字符级改为语义级，属设计选择，须预注册。

× 不应表述为："它在死机。"

Q4"零幻觉"如何保证？

由结构保证：系统不含生成器（算法 2 的返回值只能取自记忆），故只能复述听过的短语。这是其能力上限，而非它所持有的性质。

× 不应表述为："我们教会了它不许编造。"

Q5如何确认结果并非随机？

三个层面：① 对照臂（off / shuf / nodep / nodecay / bigk）；② 跨线对比（489 日旧线第一人称念头为 0，对比 66 日参照线的大量第一人称）；③ 复现（S1 三种子）。且全部判据已预注册冻结。

应主动交底：R2 六臂共用父本，未采样种子方差（见 §6.2）。

Q6本系统的工作空间与全局工作空间理论、以及语言模型中的"J 空间"差别何在？

差别在承重度。在语言模型研究中，删除该表征集合导致高阶功能崩溃[4]；在本系统中删除念头，一切照常（E6a，四项指标 < 5%）。故结论为只读。但 E6b 表明下游确实在因果地读取念头。精确表述：它改变"想要什么"与"以为自己是谁"，不改变"自己的状态"。

Q7只读是否只是因为通道过弱（±0.02）？

我们自己也持此怀疑，故实施了四级修正阶梯（表 4）：开放通路至约 26% 检索命中、切换至被消费的变量 s₄、将耦合提升至原值 15 倍（0.30，即 0.91σ）。结果：四项指标仍全部 < 10%，且对剂量不单调。故只读不是实现缺陷。

必须补足边界：写入量均值为近零，故本阶梯排除的是"平衡扰动不承重"，单符号写入尚未被测（见 §5.3.5 与 §6.2）。

Q8判定标准是否在事后被修改？

未修改。判据事前冻结（附录 C）。E1–E3、E6a、R5 均为阴性或半阴，且如实报告；E1 是预注册主预测失败，我们将其作为发现报告。唯一一次修订是 R 阶梯，其动因为在采集数据之前审计发现通道两端均不活跃，程序合规。

Q9n = 1 的个体，结论如何泛化？

这是正确的批评。论文明确承认"代码是物种，状态是个体"——研究对象是一个具有特定历史的个体（§6.2）。唯一的额外样本是 S1 的三种随机种子，且仅用于检验发育轨迹的可重复性。

× 不应表述为："它代表所有同类系统。"

Q10为何不使用大语言模型？

大模型是训练所得的字符预测器，其"内省"输出不可证伪。本文要求的是累积历史的发育个体。语言模型在本项目中的唯一位置是对话输出环节的义肢，不参与认知回路（算法 1–2 不引用任何生成模型）。

Q11零生成加 55 型语料，是否把问题做小了？

是有意为之：将变量控制到最少，才可能对结果作出归属。而 P6 正在放宽这一约束（55 → 8.33×10⁴ 型），目的正是检验"输入贫乏"是否为瓶颈（§5.4）。

Q12加速线的结果是否可信？

我们已在标注上作了区分：加速线仅作通路证据，不作最终数据。其名义倍率为 10⁹，实测约 5×10²–10³ 倍，且我们引用实测值而非名义值。实时主线当前仅 day 4。

Q13"我在这儿"是否属于过度解读？

我们不作出语义宣称。可成立的事实是：一个纯第一人称片段进入了自我模型；而此前 434 日内该类片段数为 0，原因是语料中不存在"我"类短语。该现象对应 Vygotsky 的"你 → 我"倒转[8]，且它是检索竞争的结果，非我们写入。

Q14最脆弱的结论是哪一条？

其一，只读结论中"单符号写入尚未被测"；其二，自我模型的归因未完全分离——语料与门控曾被同时修改，而 S2 的 2×2 分离显示语料才是第一人称片段的必要条件，与我们原预测相反。两条均已写入 §5.3.3、§5.3.5 与 §6.2。
