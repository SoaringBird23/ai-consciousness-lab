## 重建步骤

```bash
# 1) 取原始包（约 24.8 MB；国内直连很慢，必要时走代理）
curl -L -o corpus_raw/childes_mandarin_zh_traditional.zip \
  "https://talkbank.org/childes/access/Chinese/Mandarin/Traditional.zip"
# 2) 解压
unzip -oq corpus_raw/childes_mandarin_zh_traditional.zip -d corpus_raw/childes
# 3) 构建（需 opencc-python-reimplemented，见 requirements.txt）
./venv/bin/python tools/build_corpus.py
```

## 处理链（`tools/build_corpus.py`）

1. **取主层话语**：只保留成人说话人（MOT/FAT/INV/GRA/GRM/UNC…）；丢弃目标儿童 CHI 与同龄同胞
   ——那是同龄人语言，不是照护者语言。
2. **切分句边界**：CHAT 用 `‡`（短停顿）与 `„`（长停顿/引语）在话轮内分句，中文逗号分号同理。
   切开当独立短语，而不是整条丢弃（"太难的 ‡ 你又不会" → 两条）。
3. **清洗标注**：去行尾对齐时间戳、`0word` 零标记、`&=动作`、`(.)` 停顿、`[/]` 复述、
   `+/.` 中断、`<>`、引号；`(么)` 这类括注保留内容去括号。
4. **丢弃整句**：含 `xxx/yyy/www`（无法辨认）或匿名化占位符（`孩名/姓名/人名/地名/机构名/学校名`）。
5. **繁 → 简**：opencc `t2s`。
6. **合词**：CHAT 已按词用空格分隔，合并为自然书写形式（`拿 過 來` → `拿过来`）。
7. **长度筛选**：保留 2–8 字（默认，可 `--min/--max` 调）。
8. **末道归一**：只保留汉字，清掉残余结构符号。

## 已知限制与设计痕迹（必须如实记录）

- **分池尚未做**。原架构有四个池（EVENT / NIGHT / DAY / SELF），而 CHILDES 没有对应标注。
  把语料映射到池子需要一条**人为规则**（关键词法或频次分层），这条规则一旦写进代码就是
  观察者判断的注入点，必须在预注册里显式声明，不能藏在清洗脚本里。
- **`%spa` 语用标注未采用**。语料里确有语用层（$DJF 18123、$NIA 15242、$DHA…），但那是
  各子库自定的编码方案，缺少官方码表，无法可靠解读，故未用于分池。
- **繁简转换的损耗**：`t2s` 对台湾用词（如「嘍」→「喽」而非大陆「了」）不做词汇级归并，
  个别用词会与大陆口语略有差异。
- **筛选是价值判断**：2–8 字、只取成人、丢弃占位符——这些阈值都是选择，不是客观属性。
  改动它们会改变语料分布，实验前需固定。
